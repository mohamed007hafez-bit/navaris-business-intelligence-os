# NAVARIS Formula Registry

Store deterministic finance, accounting, valuation, ratio and break-even formulas here.

Each formula should include: Formula ID; Name; Definition; Equation; Inputs; Units; Preconditions; Edge Cases; Source/Method; Test Cases; Version.

Core formulas currently specified in docs/WORKFLOWS-EVALUATION-PROMPTS.md include FCF, EV, Equity Value, NPV, IRR, margins, ROIC, Debt/EBITDA, DSCR, break-even revenue, Expected Cash and Days-to-Cash.
