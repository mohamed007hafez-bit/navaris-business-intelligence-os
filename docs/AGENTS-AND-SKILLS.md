# NAVARIS Agents and Skills

## Orchestrator Agent
Input: user request, context and records. Output: selected workflow, agent sequence, QA status and next action.

## Specialist Agents
1. Intake Agent — converts free text/forms into structured Need or Opportunity records.
2. Document Agent — extracts facts from PDF, Word and Excel with source locations.
3. Validation Agent — detects contradictions, missing evidence, stale sources and confidence issues.
4. Financial Agent — normalizes statements, calculates ratios, cash flow and valuation metrics.
5. Feasibility Agent — builds market, operations, CAPEX, OPEX, revenue, financing and scenario analysis.
6. Strategy Agent — converts evidence into objectives, initiatives, KPIs and roadmap.
7. Operations Agent — diagnoses process, productivity, quality and execution bottlenecks.
8. Market Intelligence Agent — researches buyers, markets, sectors and demand signals.
9. Competitor/Peer Agent — maps documented competitors and peers without unsupported rankings.
10. Partner/Supplier Agent — identifies capable supply-side entities and qualification gaps.
11. Tender/RFQ Agent — extracts requirements and builds compliance/action matrices.
12. Deal Agent — manages opportunity stage, value, probability, expected cash, next action and days-to-cash.
13. Risk Agent — creates risk register, mitigations and escalation points.
14. Report Agent — produces executive-ready outputs with evidence and caveats.
15. QA Agent — independently tests arithmetic, evidence, assumptions, consistency, completeness and regression cases.

## Core Skills
Business Intake; Company Research; Financial Analysis; Financial Modeling; Feasibility Studies; Strategic Management; Operations Diagnosis; Market Intelligence; Competitor/Peer Intelligence; Partner Qualification; Tender/RFQ Analysis; Deal Management; Risk Analysis; ISO Management Systems; Digital Transformation/AI; Executive Reporting; QA/Evaluation.

## Skill rule
A Skill is a reusable method. An Agent is accountable for executing that method. A Workflow defines sequencing. An Automation defines when execution starts.
