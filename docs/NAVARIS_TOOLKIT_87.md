# NAVARIS Toolkit — 87 Checkpoints (Operating Draft)

**Status:** DRAFT — internal working framework, not certification or proof of implementation.
**Decision rule:** FACT → SOURCE → CALCULATION → ASSUMPTION → EVALUATION → ACTION.
**Cash rule:** Cash collected = 0 unless bank receipt evidence is recorded.

Each checkpoint remains UNVERIFIED until an artifact, owner, date, and reviewer are recorded.

## A. Strategy and governance (1–10)
1. Define business objective. 2. Name accountable owner. 3. Define customer segment. 4. Define buyer problem. 5. Record value proposition. 6. Separate public/private information. 7. Record approval rights. 8. Maintain risk register. 9. Set review cadence. 10. Record changes with evidence.

## B. Customer qualification (11–20)
11. Record legal customer name. 12. Identify economic buyer. 13. Identify operational user. 14. Confirm problem in buyer's words. 15. Quantify cost or delay. 16. Confirm decision process. 17. Confirm budget route. 18. Confirm timeline. 19. Record next agreed action. 20. Disqualify unsupported leads.

## C. Offer and pricing (21–30)
21. Define deliverable. 22. Define scope. 23. Define exclusions. 24. Define timeline. 25. State price/currency. 26. State payment milestones. 27. State expiry. 28. Calculate variable cost. 29. Calculate contribution margin. 30. Obtain approval before sending.

## D. Sales execution (31–40)
31. Maintain dated lead register. 32. Record source. 33. Confirm channel appropriateness. 34. Draft problem-led message. 35. Use verified facts. 36. Record sent evidence. 37. Set follow-up date. 38. Record response. 39. Schedule agreed discovery. 40. Close the loop on open opportunities.

## E. Delivery control (41–50)
41. Confirm written scope/acceptance. 42. Confirm inputs. 43. Assign delivery owner. 44. Establish baseline. 45. Record milestones. 46. Maintain version control. 47. Validate calculations and citations. 48. Record quality review. 49. Obtain customer acceptance. 50. Archive final deliverable.

## F. Cash and finance (51–60)
51. Record invoice reference. 52. Record amount/currency. 53. Record due date. 54. Record terms. 55. Record bank evidence. 56. Reconcile receipt. 57. Separate invoiced from collected revenue. 58. Track aging. 59. Calculate contribution after direct costs. 60. Do not recognize undocumented cash.

## G. ISO and audit readiness (61–70)
61. Define audit criteria. 62. Confirm scope. 63. Identify process owners. 64. Maintain document list. 65. Record revisions. 66. Maintain evidence register. 67. Record nonconformities objectively. 68. Separate correction from corrective action. 69. Verify effectiveness. 70. State that consultancy is not certification.

## H. Digital and data controls (71–80)
71. Maintain source control. 72. Protect credentials. 73. Use least privilege. 74. Validate backup/recovery. 75. Record deployment results. 76. Test links and user journeys. 77. Check mobile layout. 78. Check accessibility basics. 79. Protect customer data. 80. Record tool limitations.

## I. Management review and closure (81–87)
81. Review pipeline aging. 82. Review offers sent. 83. Review acceptance rate. 84. Review collected cash. 85. Review delivery margin. 86. Assign one next action per open item. 87. Close only with dated evidence.

## Minimum checkpoint record
| Field | Required value |
|---|---|
| Checkpoint | ID and control |
| Status | UNVERIFIED / IN PROGRESS / PASS / FAIL |
| Evidence | Direct record link |
| Owner | Accountable person |
| Date | Last checked |
| Reviewer | Independent check if applicable |
| Corrective action | Action, owner, due date |

This is a framework, not an assertion that all 87 checkpoints have passed.
