القرار يعتمد على تحليل أداء الصندوق، جودة الإدارة، مستوى المخاطر، والرسوم باستخدام معايير تقييم الصناديق

قبل الاشتراك في أي صندوق—including NAVARIS—يجب تقييمه عبر 7 محاور أساسية: الأداء، المخاطر، الرسوم، مدير الصندوق، مقارنة المؤشرات، اتساق النتائج، وملاءمة أهدافك.

1. ما الذي يجب تحليله في صناديق NAVARIS؟

  • العائد السنوي لآخر 3–5 سنوات مقارنة بالمنافسة
  • الانحراف المعياري، نسبة شارب، ألفا وبيتا
  • نسبة المصروفات وأثرها على العائد الصافي

2. تقييم الأداء السابق واتساق النتائج

  • هل يتفوق على المؤشر والأقران؟
  • هل الأداء مستقر أم متذبذب؟
  • الأداء السابق لا يضمن النتائج المستقبلية.

3. تحليل المخاطر

  • الانحراف المعياري وأكبر هبوط Drawdown
  • الارتباط بالمحفظة الحالية ومدى التنويع
  • المخاطر الأعلى لا تضمن عائدًا أعلى.

4. تقييم مدير الصندوق

  • خبرة المدير وسنوات العمل
  • نتائج موثقة في صناديق أخرى
  • استراتيجية واضحة ومنضبطة؛ نقص البيانات يستلزم الفحص.

5. الرسوم ونسب النفقات

  • الرسوم المرتفعة تقلل الربح الصافي
  • قارن مع صناديق مماثلة مصريًا وعربيًا
  • رسوم أعلى دون أداء مبرر = إشارة للمراجعة، لا حكم آلي.

6. مقارنة الصندوق بالمعايير

  • اختر مؤشرًا مناسبًا للاستراتيجية
  • قارن بأداء المنافسين للفترة نفسها
  • الأداء الأقل من المؤشر قد يشير إلى ضعف القيمة المضافة.

7. هل تشترك أم لا؟ (قرار عملي)

Excel · INPUTS / PERFORMANCE CALC

INPUTS: Date | Fund Name | Buy Price | Units | Current NAV | Dividends | Fees | Currency

Total Cost = Buy × Units + Fees
Market Value = NAV × Units
Gross P/L = Market Value + Dividends − Total Cost
Net % = P/L ÷ Cost
Annualized = (1 + Net Return)^(365 / Days) − 1
Sharpe = (Return − Risk-Free Rate) / SD
Alpha, Beta, Drawdown require dated return series.

Track realized/unrealized returns separately.

Excel · DASHBOARD

  • KPI: Total P/L, Return %, Annualized, Best/Worst Fund
  • NAV vs relevant benchmark: EGX30, S&P Energy, Baltic Dry or Brent
  • Sharpe ranking and risk period
  • Return below benchmark by 2 percentage points → Review
  • Drawdown above 15% → High-Risk Review
